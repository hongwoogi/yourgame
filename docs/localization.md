# 영어 기본값과 한국어 지원

2026-08-31 요청에 따라 영어를 기본 언어로 제공하고, 한국에서 접속한 방문자에게만 한국어를 자동 적용한다. 공개 화면과 보호된 관리자 화면 모두 우측 상단에서 `English` / `한국어`를 직접 선택할 수 있다. 모달이 열린 동안에도 언어를 바꿀 수 있다. 실제 검증·배포 결과는 운영 기록과 구분한다.

언어 선택은 닫혀 있을 때 영어에 미국 국기, 한국어에 태극기를 작은 로컬 SVG로 표시한다. 펼친 선택 목록에는 `English` / `한국어` 이름을 유지한다. 키보드와 화면 낭독기로도 언어를 선택할 수 있으며 터치 영역은 최소 44×44px이다. 국기는 언어 선택 상태를 나타내며 사용자의 국적이나 현재 접속 국가를 표시하지 않는다.

모바일 메인 상단바는 로고·국기·계정 버튼을 한 줄로 제공한다. 좁은 화면에서 계정 버튼은 아이콘으로 줄이고 표시 이름은 시각적으로 숨기되 접근성 이름과 로그인·로그아웃·관리자 이동 동작을 유지한다. 관리자 화면 주소는 `/master`이며 권한은 기존과 같이 서버에서 확인한다.

## 언어 선택 순서

1. 단일 `?lang=en` 또는 `?lang=ko`가 있으면 해당 언어를 명시적 선택으로 적용하고 저장한다. 레딧 등 영어 공유에는 `https://yourga.me/?lang=en`을 사용할 수 있다.
2. 저장된 수동 선택이 있으면 접속 국가보다 우선한다. 브라우저 저장소의 `yourgame.language.v1`, 이후 `yourgame_language` 쿠키를 확인한다.
3. 수동 선택이 없고 신뢰된 Vercel 접속 국가가 `KR`이면 한국어를 적용한다.
4. 그 외 국가·국가 정보 없음·조회 실패는 영어다. 브라우저 언어가 한국어여도 한국 외 접속을 한국어로 자동 바꾸지 않는다.

수동 선택은 새로고침 없이 적용되며 다음 방문에도 유지한다. 기존 주소의 `lang` 값도 선택에 맞게 바꾸되 다른 쿼리와 해시는 보존한다. 저장소나 쿠키를 사용할 수 없어도 현재 페이지에서는 선택이 적용된다. 다른 탭의 수동 선택도 반영하며, 늦게 도착한 국가 조회나 과거 탭 알림이 최신 수동 선택을 덮어쓰지 않는다. 국가에 따른 자동 선택은 수동 선호로 저장하지 않는다.

## 국가 조회와 개인정보

`GET /api/locale`은 `{ locale, source, supportedLocales }`를 반환한다. `source`는 `preference`, `country`, `default` 중 하나다. 이 경로는 DB·세션 생성·Google 인증에 의존하지 않는다. 브라우저는 최대 2초 동안 조회를 기다리며 그동안도 영어 화면을 제공한다. 조회에 실패해도 언어 선택을 사용할 수 있다.

서버는 정확한 `X-Yourgame-Language: en|ko`, 중복되지 않은 유효 언어 쿠키, 신뢰된 한국 접속 정보 순으로 판정한다. 쿠키·헤더의 다른 값이나 중복 값은 언어로 해석하지 않는다. 국가 헤더는 `VERCEL=1`이면서 `VERCEL_ENV=production|preview`인 실행 환경에서만 사용한다. 로컬·다른 호스트에서 전달한 국가 헤더는 자동 판정 근거가 아니다. 응답은 캐시하지 않으며 언어 관련 헤더와 쿠키를 `Vary`에 명시한다.

Vercel의 `x-vercel-ip-country`는 방문자의 공개 IP에서 얻은 국가 코드다. VPN·프록시나 위치 데이터 오차로 실제 위치와 다를 수 있으므로 수동 선택을 항상 제공한다. 이 기능 때문에 외부 위치 조회 서비스를 호출하거나 원시 IP·위치 이력을 별도 저장하지 않는다. 언어 값은 인증·관리자 권한·안전 심사·접수 제한의 근거로 사용하지 않는다. 근거: [Vercel 요청 헤더](https://vercel.com/docs/headers/request-headers), [Vercel 시스템 환경 변수](https://vercel.com/docs/environment-variables/system-environment-variables).

## 번역 범위와 유지할 데이터

- 공개 화면의 간결한 소개·개발 과정·카운트다운·마감·2,000 UTF-8 바이트 제한·최근 60분 3회 제한·로그인·접수·수정·투표·기여도·운영 상태·오류를 번역한다. Teen 안내와 사전 안전 심사 표시는 메인 화면에서 제거한다.
- 관리자 화면의 접근 안내·회원·제안·개발 요청·운영·안전 점검표·감사 이력의 고정 UI와 동작 결과를 번역한다.
- 제목·설명·공유 미리보기·자바스크립트 비활성 안내의 원본 HTML은 영어다. 문서 언어, 입력 안내와 접근성 이름도 선택에 맞게 바꾼다.
- 카운트다운은 남은 총 시간·분·초만 표시한다. 24시간 이상 남으면 시간을 24로 나누어 버리지 않는다. 배포 목표의 절대 시각은 바꾸지 않고 한국어는 `Asia/Seoul`, 영어는 워싱턴 D.C.의 `America/New_York`로 표시한다. 동부 표준시/서머타임(`EST`/`EDT`)은 해당 날짜에 맞춰 자동 적용한다. 첫 공개 목표는 한국어에서 2026-09-01 00:00 KST, 영어에서 Aug 31, 2026 / 11:00 AM EDT다. 언어 전환 때문에 접수 회차나 카운트다운을 재설정하지 않는다. 제안 작성·마감·횟수 회복 등 다른 시각은 기존의 명시적인 KST 표시를 유지한다.
- Google 버튼에는 선택한 `locale`을 전달한다. 언어 전환은 버튼 표시만 갱신하며 로그인 초기화·nonce·전송 의도를 새로 만들지 않는다. Google 계정 선택·동의 화면 자체는 Google이 관리하므로 앱 전체 UI 번역 검증과 실제 계정 로그인 성공을 구분한다. 근거: [Google 버튼 locale 설정](https://developers.google.com/identity/gsi/web/reference/js-reference#locale).

참여자 프롬프트 원문, 표시 이름, 이메일, 관리자 사유·개발 정리문·직접 작성한 운영 공지는 자동 번역하지 않는다. 안전 심사에 묶인 원문·revision·정책·해시는 그대로 유지한다. 현재 작성 중인 제안·수정본·체크박스·관리 작업 사유·확인 입력도 언어 전환으로 지우거나 자동 제출하지 않는다.

서비스 종료·재개 확인 토큰은 언어와 무관하게 각각 정확한 `END SERVICE`, `RESUME SERVICE`다. 서버는 기존 한국어 확인 토큰도 이전 클라이언트와의 호환을 위해 허용한다. 확인 토큰 변경은 최근 15분 이내 재인증·권한·CSRF·최신 revision 검사를 완화하지 않는다.

아직 공개되지 않은 실제 게임도 영어 기본·한국어 선택과 9:16 모바일 화면을 기준으로 만들어야 한다. 언어 선택은 공개 여부를 바꾸지 않는다. 제안 공개는 별도 `public-default-v1` 정책을 따르며, 현재 화면 변경을 실제 게임 생성·공개 성공으로 표시하지 않는다. 제안 원문·내 제안 모달에서도 같은 국기 선택창으로 언어를 바꾸고 원문·초안을 유지한다.

## 검증 기준

빌드에서 영어·한국어 번역 키와 치환 변수의 일치, 정적 HTML의 번역 키 누락을 검사한다. 서버 테스트는 신뢰할 국가 정보·잘못되거나 중복된 선호·언어별 API 오류·비공개 데이터 보존을 확인한다. 브라우저 테스트는 한국·해외 자동 선택, 수동 우선순위, 늦은 응답, 저장소 차단, 영어와 한국어의 로그인·제출·수정·관리 작업, 모바일 가로 넘침과 입력 보존을 확인한다.

자동 테스트의 국가·Google 응답 대체는 여러 국가의 실제 네트워크 접속이나 실제 Google 계정 인증을 완료한 증거가 아니다. 운영 확인은 배포된 커밋·언어 API·실제 Google 버튼 응답·언어 전환·익명 권한 거부를 별도로 검사하며 운영 데이터에 시험 제안을 넣지 않는다.
