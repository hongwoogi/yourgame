# 큰 틀을 유지하는 누적 진화

이 실험은 개인들의 방향성이 정합되어 게임이 나아지는 것을 목표로 하므로, 최초 제안 수집 기간의 요구로 첫 게임과 핵심 규칙을 함께 확정하고 이후 핵심 목표와 플레이의 기본 반복 구조를 보호한다. 이 큰 틀을 바꿔야 하는 제안은 자동 제외하며, 매번 장르와 규칙을 자유롭게 뒤집는 방식 대신 같은 게임을 누적해서 정교화하는 방식을 택한다. 이 선택은 초기 방향이 이후의 제안 가능 범위를 제한한다는 대가가 있으며, 구체적인 초기 확정 절차와 위반 판정 방식은 별도로 정한다.

## 대체된 결정

위 기록은 Q6 시점의 결정이다. 이후 Q14에서 사용자가 로그라이크 장르만 고정하고 목표·전투·성장 구조는 이후에도 변경하는 제안을 수락했으므로 [ADR-0003](0003-roguelike-genre-boundary.md)으로 대체한다. 최초 핵심 구조를 바꾼다는 이유만으로 제안을 자동 제외하지 않는다.
