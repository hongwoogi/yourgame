# 로그라이크 장르를 경계로 한 진화

참여자들의 방향성이 정합되면서 게임이 발전하도록, 최초 게임의 목표와 반복 구조를 영구 고정하는 대신 로그라이크 장르만 유지하고 전투 방식·목표·성장 구조는 이후 버전에서도 변경할 수 있게 한다. 장르를 벗어나는 제안은 자동 제외하되, 기존 핵심 구조가 바뀐다는 이유만으로 제외하지 않는다. 이는 초기 구조에 갇히는 문제를 줄이는 대신 장르 내 큰 변화가 가능해지는 선택이며 [ADR-0001](0001-preserve-core-game-framework.md)을 대체한다.
