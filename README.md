# yourga.me

참여자의 제안을 모아 하나의 솔로 로그라이크 게임을 함께 진화시키는 실험입니다.

GitHub·Vercel·Turso·도메인 연결을 완료했으며, [yourga.me](https://yourga.me)에서는 준비 페이지를 제공합니다. 게임 공개와 최초 제안 모집은 아직 시작하지 않았습니다.

- 코드와 이력: GitHub
- 웹 서비스: Vercel
- 운영 데이터: Turso
- 도메인: Cloudflare에서 관리하는 `yourga.me`
- 게임 변경과 검증: 운영자의 PC에서 실행하는 Codex

제품 합의와 미확정 사항은 [설계 기록](docs/design.md)을 참고하세요. 운영 인증 정보는 저장소에 포함하지 않습니다.

연결한 리소스와 검증 범위는 [인프라 연결 상태](docs/infrastructure-status.md)에 기록합니다.
